# WIJAR Submission Gate

Source of truth: Westcliff International Journal of Applied Research (WIJAR) Author Guidelines, checked August 11, 2026.

## Blind manuscript gate

Before creating a final submission package, verify all items below:

- [ ] Original, unpublished work; not under review elsewhere.
- [ ] APA 7th edition citations and references.
- [ ] Manuscript is **under 5,000 words**, excluding the separate title page.
- [ ] Microsoft Word `.docx` format.
- [ ] Blind manuscript contains title, abstract, main text, tables, figures, and references but **not the title page**.
- [ ] No author names, affiliations, acknowledgements, document metadata, or self-identifying references remain in the blind file.
- [ ] Times New Roman, 12-point.
- [ ] Double-spaced throughout, including references.
- [ ] **No headers or footers.**
- [ ] Full manuscript title at the top of the first page.
- [ ] Abstract is 100–300 words and summarizes purpose, methods, findings, and implications.
- [ ] At least three keywords.
- [ ] Section order: Abstract, Introduction, Literature Review, Methods, Results, Discussion and Implications, Conclusion, References.
- [ ] Methods and Results are clearly labeled.
- [ ] APA 7 heading hierarchy is consistent.
- [ ] Each figure/table is introduced and discussed in the text.
- [ ] Each figure/table is placed near its first citation.
- [ ] Every figure/table has a concise descriptive title and is legible at reduced size.
- [ ] Tables are real Word tables, not images.
- [ ] References begin on a separate page, are alphabetized, double-spaced, and APA 7 compliant.
- [ ] References include current/relevant scholarship where appropriate.
- [ ] Required ethics/IRB proof is supplied when applicable; public secondary benchmark analysis must be described accurately without inventing an IRB status.
- [ ] Completed WIJAR submission checklist is uploaded as a supplementary file.

## Separate title page gate

The separate title-page `.docx` must contain:

- [ ] Full manuscript title.
- [ ] Author full name(s).
- [ ] Academic title(s), when applicable.
- [ ] Institutional affiliation(s).
- [ ] Department(s).
- [ ] City and country.
- [ ] Contact email(s).
- [ ] ORCID for each author.
- [ ] Total manuscript word count.
- [ ] Conflict-of-interest disclosure.

## Project-specific result gate

In addition to the journal formatting gate, this Part 2 manuscript is not submission-ready until:

- [ ] authorized public benchmark files have been downloaded and checksummed;
- [ ] frozen leakage-safe splits have been recorded;
- [ ] baseline and proposed models have been executed;
- [ ] Figures 1–10 and Tables 1–9 match `docs/FIGURE_TABLE_REGISTRY.md`;
- [ ] every Abstract/Results/Discussion/Conclusion number traces to the accepted run;
- [ ] model-complexity evidence answers the reviewer concern about whether an ensemble gain justifies added cost;
- [ ] `scripts/research_gate.py` passes;
- [ ] the final `.docx` is rendered and visually inspected page by page before upload.
