# Manuscript workspace

The pre-submission WIJAR manuscript is intentionally **not committed to this public repository** while the study is under execution/review. Local manuscript files (`paper/manuscript.md`, `.docx`, `.pdf`) are gitignored.

This avoids accidentally publishing a draft, exposing author metadata in a blind-review workflow, or creating confusion between executable research artifacts and unexecuted manuscript placeholders.

The public repository contains the research protocol, figure/table registry, WIJAR submission gate, code, tests, and reproducibility infrastructure. After journal policy permits public release, an accepted-manuscript/supplement folder can be added with the exact accepted run ID and Git commit.
